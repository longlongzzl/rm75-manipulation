### S1. 原生 runtime 的生命周期与三类世界所有权【最高优先级】

**观察。** `swm/integration.py` 的 `_FACTORIES` 仍为空；注册函数存在，但 worker 子进程没有安装完整工厂。现工厂协议返回 runtime、requests、goals_check，没有建立完整资源上下文与退出清理合同。

**完成要求。**

明确三个世界：

- **被观测世界**：真实世界，或承担地面真值的主物理仿真。只有实际执行与显式记录的外部干预可改变它，不能为“同步”把目标写进去。
- **同步镜像世界**：SWM 实测状态的私有规划/仿真副本。允许在 idle 检查点设置关节、物体与约束以对齐实测；不能将“执行中不可 teleport”的规则错误地用于阻止镜像初始化。
- **假设世界**：辨识和规划时创建的私有副本，可以重置、改参数、并行计算；不得持有真实 executor，也不能污染被观测世界或当前镜像。

已有同名几何库与工具都复用；该区分是所有权，不是另建三个业务框架。

**最先验收。** 正常启动一个新的 worker，仅完成“笔”的原生 grasp/place；六个检查点来自不同采集，世界实际读回一致。关闭/取消后相机引用、sim、planner、子进程、文件、锁与 action recorder 无本任务泄漏。至少一个端到端先通过，再扩大任务。

**完成要求。**

1. 保留原成功版本的抓放关系筛选与必要策略。**联合考虑可行性，原子化执行**：选择抓取关系时可以测试后续放置是否可达；禁止提前把放置轨迹当作无需抓后验证即可执行的指令。

3. 反向 retreat 可作为候选保留，但需在“物体已释放、实际/预测释放位置、夹爪打开”的状态下重新审核，不能以附着物搬运时的检查替代。测例包括：下降无碰撞但张开后退让碰撞、计划失败后的下一候选、闭合/空手状态切换。
4. 不把“保持开放夹爪”和“没有持物”混为一项。SWM 应有独立的夹爪几何状态和持物证据，执行器与模型两边应用。
